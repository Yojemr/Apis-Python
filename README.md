# Apis-Python

Proyectos de API en Python desarrollados durante las clases.

## Proyectos

- [Py-Fast-api](Py-Fast-api/README.md): modelos de aprendices, conexión MongoDB y serialización de documentos. La aplicación y sus rutas siguen en desarrollo.

## Desarrollo

Las credenciales se mantienen en archivos `.env` locales. Los entornos virtuales no forman parte del repositorio.
Los mensajes de commit siguen [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/).
Las comprobaciones automáticas ejecutan pruebas aisladas, sin acceder a MongoDB.

Las reglas de colaboración se encuentran en [CONTRIBUTING.md](CONTRIBUTING.md).
